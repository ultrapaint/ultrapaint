# Content

The words of a design: what each thing is called, what each button does, what an error or an
empty place says. A design is judged with the words it will hold, so write real copy, at realistic
lengths, in the product's voice, and say each thing the way the product always says it. This part
is a router of its own: the voice in `references/content/voice.md`, a screen's words in
`references/content/interface.md`, a public page's in `references/content/pages.md`.

## Steps

The same whether the words come with a design or are the whole task: a screen's strings
rewritten, a page's copy written or reviewed.

1. **Settle the voice** (`references/content/voice.md`): what DESIGN.md's Content section chose
   and the words the product already uses, then the defaults there.
2. **Read the reference for the place**: `references/content/interface.md` for a product's
   screen, `references/content/pages.md` for a public page.
3. **Write real words at real lengths** (below).
4. **Finish with the check.** Run the "Before you finish" table of this file and of each one you
   read, and fix what fails.

## Real words at real lengths

Names, amounts, dates and messages look like the product's own: plausible, varied, in its
language. Put the awkward lengths beside the tidy ones: a long name next to a short one, an
amount with many digits, a paragraph that wraps twice. A specific figure beats an adjective:
"750,000+ clients", not "thousands of happy customers".

## Before you finish

| You see | Fix |
| --- | --- |
| Lorem ipsum, "Title", "Item 1" | Real copy |
| A legend on a chart, a title over a block its tabs already name | Delete it; shrinking is not enough |
| "vs last year" after a change, "Enabled" beside a switch, "17 rows" under a table, "5 of 5" over a stepper, a title over a toolbar | Remove it: the thing beside it already says so |
| A plain value ("Moderate") turned into a coloured status badge | Plain text, as the brief writes it |
| A badge on every card, or one thing marked three ways (tab, fill, border) | One badge, only for a state nothing else shows |
| "Thousands of happy customers" | The number |
