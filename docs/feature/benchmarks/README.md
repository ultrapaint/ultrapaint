# Benchmark: what a task costs an agent

Generated by `apps/server/bench/report.ts` from the runs in this directory.

Three arms: the tool as it was, the project briefing on a session's first prompt, and the briefing
plus the editor's own MCP server. Every run in every arm produced correct work — what changes is
what the agent spent finding its way.

| Task | baseline | briefing | mcp |
|---|---|---|---|
| new-page | 28 calls · 279s | 28 calls · 208s | 18 calls · 103s |
| use-component | 34 calls · 185s | 6 calls · 44s | 5 calls · 43s |
| form-from-catalogue | 41 calls · 293s | 33 calls · 234s | 13 calls · 75s |
| router-link | 19 calls · 118s | 17 calls · 116s | 7 calls · 73s |

## Totals

- baseline: 30.5 calls on average over 4 runs
- briefing: 21.0 calls on average over 4 runs
- mcp: 10.8 calls on average over 4 runs

## What it means

The briefing takes a third off, the MCP two thirds. They are not alternatives: the briefing tells
the agent the project exists and the tools do, the tools answer what it asks next. The tasks that
gain most are the ones that need the palette — a form built from the design system fell from 41
calls to 13 — and the ones that gain least are those where the work itself is the cost.

`other` is the agent calling our MCP server: ten calls answered what used to take dozens of reads.

- briefing: 84 tool calls — execute 84
