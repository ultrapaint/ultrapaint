# ADR 0004: ACP as the only agent interface

Status: accepted, 2026-09-17. Confirms D9. Amended 2026-10-26 by [0031](0031-the-desktop-app.md):
the files a turn changed are found without git.

> Amended by [0046](0046-deep-modules-fifth-review.md), 2026-10-30: SDK 1.6; the adapter keeps its updates' order and reopens a thread with `session/resume` before `session/load`; what the agent advertised is read in one module (`negotiated`), and the editor signs nobody in on its own; no permission is answered from memory; usage from ACP's typed messages; a streamed chunk travels alone.

## Decision

`packages/acp` is the only module that imports `@agentclientprotocol/sdk` (1.4.0 then; 1.6.0 since ADR 0046). It exposes
`spawnAgent(config, { cwd, handlers })` which starts the process, wires stdio through
`ndJsonStream`, registers client handlers (`session/update`, `session/request_permission`,
`fs/*`, `terminal/*`) and returns typed methods for initialize, session creation and loading,
prompt, cancel, modes and configuration options.

Launch configurations are data (`AgentConfig`): command, args, env, package, auth hint, and what
ADR 0013 adds for the sandbox (`stateDirs`, `sandboxEnv`, `sandboxMeta`). Two ship
built in, `@agentclientprotocol/claude-agent-acp` and `@agentclientprotocol/codex-acp` (the
`@zed-industries/*` names in the work definition are deprecated aliases). A JSON file under
`~/.ultrapaint/agents/` adds another agent without code changes.

The thread service projects `session/update` notifications into a transcript, routes permission
requests to the UI with per-thread remembered decisions, confines filesystem calls to the repository through the same path guard as
the editor and terminal calls through the sandbox of ADR 0013, snapshots git state to
attribute changed files to a turn (since 0031: the time and size of every file `.gitignore`
keeps, no git needed), and resumes sessions with `session/load` when advertised.

## Verified

Claude Code: initialize, session with five modes and four configuration options, prompt with
tool calls, a permission round trip in Manual mode, cancel path, changed-file attribution.
Codex: initialize (two auth methods), session with configuration options, prompt reached the
model and was refused by the account's usage limit; the protocol path is complete.
