# Research

Settings for [`/up-research`](../../.agents/skills/up-research/SKILL.md). The skill's
`## Settings` section defines each one.

## Destination

Somewhere else: a Markdown file in the evals' data directory (`ULTRAPAINT_EVALS_DATA`, else
`~/Code/ultrapaint-data`), at `research/<YYYY-MM-DD>-<slug>.md`, outside git. Nothing is published
on GitHub: no Discussion, no issue comment, no file in this repository.

The note takes the skill's form, its first line `> Research evidence, not a rule. The decision
lives in the gap or ADR that cites this note.` A gap, an ADR or a PR that it fed cites it by that
path, beside the conclusion in one line (`evals/gaps/README.md`).
