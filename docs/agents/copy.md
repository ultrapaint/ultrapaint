# Copy

Settings for [`/up-copy`](../../.agents/skills/up-copy/SKILL.md). Its `## Settings` section
defines each one.

## Copy standard

- **The reader:** a designer or a developer designing their app with coding agents, in their own
  repository.
- **Protected terms:** Ultrapaint; its command, `ultrapaint`, always lowercase in code form; and
  every name in [`GLOSSARY.md`](../../GLOSSARY.md) (canvas, page, frame, design system, Library,
  …), used as the glossary writes them.
- **Languages:** English only. There is no translation library: strings are written in the source.
- **The rules** are the product's and the design skill's, read there rather than copied here:
  [`DESIGN.md`](../../DESIGN.md) for Ultrapaint's voice (terse, technical and exact), and the
  design skill's `### Words` ([`skills/ultrapaint/SKILL.md`](../../skills/ultrapaint/SKILL.md))
  with `references/words/interface.md` for a screen's words, `pages.md` for a page's and
  `voice.md` for how a product sounds.
